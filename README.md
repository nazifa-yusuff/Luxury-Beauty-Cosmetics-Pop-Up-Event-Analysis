# Luxury-Beauty-Cosmetics-Pop-Up-Event-Analysis
Interactive cosmetic event analytics dashboard developed using  Power BI. this dashboard uses the  drill through and rank parameters features and the data modelling  of power BI.
This report contains comprehensive dashboard on luxury brand cosmetic products all over the world, categorized by region and city. The report covers twenty four luxury cosmetics brands and  provides information on the event sales in different parts of the world.
